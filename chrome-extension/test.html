Telegram Disappearing Photos Extension - Test Page

⚠️ Instructions:

  1. Open Telegram Web A in another tab
  2. Open a chat conversation
  3. Open the browser console (F12)
  4. Test the functions below

Test 1: Send from File Picker

Opens a file picker to select an image and send as disappearing photo

Test 2: Send from URL

Send a disappearing photo from an image URL


Test 3: Send from Canvas

Create a test image and send it


Console Commands:

You can also use these functions directly in the console:

sendDisappearingPhoto(file, ttlSeconds)
sendDisappearingPhotoFromUrl(url, ttlSeconds)
sendDisappearingPhotoFromInput(ttlSeconds)
